# r165 — стенд для завтрашнего теста владельца и инструкция на пять минут

## ЦЕЛЬ

Владелец завтра хочет **сам** пройти путь «книга → герой → игра» и получить
рабочий прототип. Значит к утру должно быть: приложение поднято на текущем HEAD,
профиль без мусора от прошлых прогонов, книга под рукой, и короткая инструкция —
что нажимать, что считать успехом, что прислать, если сломалось.

## ЧТО СДЕЛАТЬ

1. **Стенд.** `solo-app.service` (user-юнит, `Restart=always`,
   `~/.hermes/scripts/serve_solo.py`, порт 19215) поднят с профилем
   `runtime/web-local`. Проверить: `systemctl --user is-active solo-app`,
   `curl -s 127.0.0.1:19215/api/health` → `commit` совпадает с `git log -1 --format=%h`
   дерева движка. Расхождение — перезапустить юнит и проверить снова.
2. **Профиль.** Убрать мусор прошлых прогонов, НЕ трогая живые данные:
   `runtime/rNNN-live*` этой и прошлых задач (сначала `ps -eo cmd | grep -o
   'runtime/rNNN-live[^ ]*'` — что держит процесс, не удалять), плюс сборники-пробы
   в библиотеке только по правилу из `solo-realms-foreman` (SQL с бэкапом).
   НЕ удалять: `runtime/books/`, `runtime/web-local/`, `cloud-secrets`,
   `cloud-usage.sqlite3`, `runtime/backups/`.
3. **Книга.** В `runtime/books/` должны лежать `Hoard of the Dragon Queen RUS.pdf`
   и `The Rise of Tiamat RUS.pdf` (в git не идут). Если нет — `rclone copy` из
   `hermes-drive:Материалы Solo Realms/`.
4. **Инструкция `reports/HOW-TO-TEST.md`** — для человека, не для агента:
   - как открыть приложение (SSH-туннель/адрес, что ввести);
   - шаги: «Начать приключение» → загрузить книгу → дождаться модулей → выбрать
     модуль → герой (класс/подкласс) → начать кампанию → три реплики (осмотреться,
     «Показываю игрокам карту …», атака/проверка) → где смотреть карту и раздатку;
   - **что считать успехом** по каждому шагу (одна строка на шаг, проверяемо);
   - что прислать при поломке: экран, текст ошибки, время, шаг.
   - Сколько идёт каждый шаг (импорт 107 страниц — около минуты), чтобы не ждать
     молча.
5. **Честный блок ограничений** в конце инструкции: чего в прототипе ещё нет
   (54 правила `adjudication_required`, опыт печатной награды не идёт в счётчик,
   свободное описание карты словами не поддерживается, лимит зрения модели).
   Владельцу важно знать это ДО теста, а не после.
