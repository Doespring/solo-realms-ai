# r153 — топонимы: «Город Чудес» и «Колодец Драконов» целиком, а не обрубок

## ЦЕЛЬ

Имя локации из книги берётся вместе с существительным-видом, если оно стоит
перед именем: «Город Чудес» → «Город Чудес», «Колодец Драконов» → «Колодец
Драконов», «Болото Мертвецов» → «Болото Мертвецов». Сейчас берётся только
имя собственное после вида, и локация называется «Чудес».

Источник факта — собственный отчёт r150 («Ограничения»): «Имя локации берётся
из имени собственного после существительного-вида: „Город Чудес“ даёт локацию
„Чудес“ — фрагмент; склейку вида с именем в родительном падеже („Колодец
Драконов“, „Болото Мертвецов“) движок пока не умеет».

## ЧТО ДОЛЖНО ОСТАТЬСЯ

- Место без имени собственного по-прежнему получает якорь главы (`binding='title'`),
  а не выдуманное имя.
- Колонтитул с переводчиками («Эпизод 5 — LeoTrickster, stivie») названием не
  становится (есть тест в `test_module_scene_from_book.py`).
- `quote` по-прежнему точный срез страницы (`source_span`), имя входит в цитату.
