### 3. Прогресс не спорит сам с собой

| что | «до» (n16) | «после» (n1) |
|---|---|---|
| число готовых блоков | «Подготовка: 3 / 5 блоков» строкой экрана + «3 из 5 частей» в aria + «Часть 5 из 5» | **одно**: «Готово 3 из 5 · не вышло: 1» |
| заливка | 60 % при «Часть 5 из 5» | 60 % при «Готово 3 из 5» — сходится |
| счётчиков времени | два: часы 1:36 → 1:37 (прошло) и «осталось ≈3:00» | **один**: «осталось 3:00», идёт вниз (замер 3:00 → 2:58) |

`Часть N из M` считалась по обработанным (готовые + упавший), заливка — по готовым,
поэтому числа расходились. Теперь и полоса, и строка говорят про готовое. Строка
экрана `web/creation.js` больше не дописывает ` · done / total` — счётчик блоков
живёт только в панели; тест проверяет, что вне панели нет ни «Подготовка: N / M»,
ни дописки «… · N / M» (у файла «1 / 1» — это извлечение файла, не блоки книги).
