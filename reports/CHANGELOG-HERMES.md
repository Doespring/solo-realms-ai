## Что это за проект

Соло-партия в D&D 2024: игрок ведёт героя, ИИ работает мастером. Внутри — свой движок правил
(позиция, инициатива, заклинания, предметы, состояния), приложение на Python с веб-интерфейсом и
облачная модель для реплик мастера и подготовки приключения из книги.

Задача, под которую всё делалось: **играть одному, с телефона, без знания правил** — правила считает
движок, а не модель.

## Что построено

### Движок правил Nat20

- **Позиция, движение, инициатива, бой** — свой расчёт, не «на словах модели».
- **Заклинания целиком:** слоты, цели, концентрация, @scale-токены (Rage, Sneak Attack), каст без
  цели больше не тратит слот впустую.
- **Предметы и состояния:** повторный клик снимает эффект, prone-подъём стоит половину скорости.
- **Карта классов PHB 2024:** 201 заблокированное правило разобрано до 90 проверенных, 54 честно
  отданы на решение мастера.
- **Проверки говорят числами:** «Выживание: 13 против Сл 12 — успех» вместо «вам повезло».
- **Партия:** кампания хранит героя и спутников с отдельными листами, спутники сами ходят в бою,
  слышат приказ, но решают сами; смерть по договорённости, выбор сложности; NPC становится
  сопартийцем по ходу игры.

### Подготовка приключения из книги

- **Три источника — одна форма:** PDF, Markdown, JSON дают одинаковую форму приключения.
- **Живой разбор PDF:** реальный файл режется на блоки по 16 000 символов с сохранением прогресса,
  незаконченные блоки можно продолжить.
- **Сценарий из книги с цитатой страницы:** локации, NPC и проверки со ссылкой на страницу.
- **Схема ответа строгая (r227):** схема собирается из моделей кода и уходит провайдеру как
  `json_schema strict`; мусорные ключи отсекаются санитайзером, один ремонт на блок.

### Игра и интерфейс

- **Экран «Стол и лист»** вместо прежней панельной вёрстки: лента, поле ввода, лист героя, кубик.
- **Светлая и тёмная темы** с проверенным контрастом.
- **Режим «только чат»:** один экран, панельные скрипты не подключаются.
- **Редактор героя**, «Начать приключение» одним диалогом, оффлайн-ошибки вместо молчания.
- **88 замеров приёмки** интерфейса на 375 и 1440 px настоящим браузером.

### Модель, ключи, деньги

- **Профили под роли:** мастер, второй мастер, чтение книги, переводчик — у каждой своя модель и
  лимит.
- **Хранилище ключей на Linux:** keyring / файл вместо жёсткой привязки к Windows.
- **Учёт расходов:** свой счётчик вызовов и стоимости.
- **Потолок ответа считается из `max_tokens`:** 2048 → 96 КБ, 8192 → 192 КБ.

### Инфраструктура

- Сервис приложения на VPS, публичный доступ через мост с паролем и туннель, сам поднимается после
  падения.
- Мост подменяет Host/Origin — приложение слушает только localhost и чужие заголовки режет.
