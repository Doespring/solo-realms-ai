# Как проверить стенд за 5 минут

Написано для владельца. Числа ниже сняты **7 ноября 2026, 06:22–06:52 UTC** на живом
стенде (`runtime/web-local`, порт 19215) запросами к `/api/health`, к API библиотеки и
глазами в браузере — не из планов.

**Стенд:** коммит `5da4aeda` (ветка `work/nat20-engine`), версия `2.2.0-prototype.5`.
После него в дерево легли только коммиты `n10`, которые меняют `reports/` — код и движок
с тех пор не двигались. Стенд перезапущен последним, поэтому `health.commit` равен
`git rev-parse --short HEAD` на момент твоего теста.
**Публичный вход погашен** по твоему распоряжению: `solo-public.service` и
`cloudflared-solo.service` остановлены, порт 19999 не слушает, `solo-entry-health.timer`
снят с автозапуска. Туннель не поднимаю.

---

## 0. Открыть приложение (один раз, ~1 минута)

Приложение слушает только `127.0.0.1:19215` на сервере, поэтому нужен SSH-туннель.
В PowerShell **на своём компьютере**:

```powershell
ssh -N -L 19215:127.0.0.1:19215 hermes@144.31.34.190
```

Окно с туннелем не закрывать всё время теста; оно висит пустым — это нормально.
Затем в браузере: <http://127.0.0.1:19215/> (первый раз — **Ctrl+F5**, иначе браузер
покажет старые JS/CSS от прошлой сборки).

Если туннель не поднимается — та же команда с `-v` покажет причину (ключ не найден /
не принят / клиент пробует пароль). Вводить её в консоли самого VPS бессмысленно:
на сервере вход по паролю выключен, только ключом.

## 1. Шаг 1. Приложение крутит текущий код (30 секунд)

В том же окне PowerShell:

```powershell
curl.exe -s http://127.0.0.1:19215/api/health
```

**Критерий успеха:** страница открылась, в полосе меню «Игра · Кампании · Персонаж ·
Мастер» и «Ещё»; в ответе `health` `commit` **совпал** с последним коммитом дерева
(`git -C /home/hermes/projects/SoloRealmsAI-Nat20 rev-parse --short HEAD`). На момент
проверки стенда это было `5da4aeda`; после него я коммитил только `reports/`.

Полезное в том же ответе: `"cloud":true` — ходы идут через облачную модель и стоят денег;
`"readiness":{"status":"configured"}` — модель настроена, но в этом процессе ещё не было
успешного ответа; `ready` — ответ уже был.

**Как выглядит провал:** `health` молчит / 500, либо `commit` другой. На старой сборке
тест ничего не докажет — писать мне, стенд перезапустят.

## 2. Шаг 2. Библиотека не пуста (1 минута)

1. «Ещё» → **«Библиотека приключений»**.
2. Первая карточка: «Материалы нового приключения · комплект 1 из 35».
3. «Открыть комплект» → **«Подготовка Мастера — содержит спойлеры»**.

**Критерий успеха:** в карточке «Источники: 1 · Страницы: 107 · Модулей: 8»; в закрытой
подготовке раздел «Отдельные приключения» с восемью главами — «Эпизод 1: Гринест в огне»,
«Эпизод 2: Лагерь налетчиков», «…», «Эпизод 8: Замок в облаках», и у каждой кнопки
«Открыть инструкции модуля / Создать героя / Продолжить с текущим героем / Подключить
сценарий к кампании». Это книга Hoard of the Dragon Queen, залитая и разобранная при этой
проверке (107 страниц, 501 244 знака за 23 секунды, 8 модулей `ready`).

Пометка «инструкции требуют проверки» — честная: главы нарезаны автоматом, человеком не
вычитаны. Это не поломка.

## 3. Шаг 3. Герой и один ход (3 минуты)

**Подготовленное приключение уже лежит — модель для этого шага не нужна.**

1. «Кампании» → карточка **«Город Дис — начало»** (статус «Готово к созданию героя») →
   **«Создать героя»**.
2. Конструктор: «Создание героя», «Шаг 1 из 5 · Раса», девять видов (Драконорождённый,
   Дварф, Эльф, Гном, Голиаф, Полурослик, Человек, Орк, Тифлинг).
3. По шагам: Раса → Класс → Прошлое → Характеристики → Готово. Внизу «Назад», «Дальше»,
   «Рекомендовать» (заполняет оставшееся за тебя), «Подтвердить героя» (серая, пока шаги
   не закрыты — это нормально).
4. Вписать имя → **«Подтвердить героя»** → открывается экран «Игра».
5. В поле «Что делает ваш герой?» написать `Осматриваюсь.` и нажать **«Сказать»** (или Enter).

**Критерий успеха:** на шаге 1 видны девять видов (у заклинателя шагов шесть — добавляется
«Магия»); после подтверждения героя экран «Игра» показывает лист героя с хитами, поле ввода
и вопрос Мастера; на реплику в ленте появляется ответ Мастера, а номер хода в шапке растёт.

**Быстрая альтернатива, если не хочется собирать героя:** «Кампании» → **«Р239 Проверка»**
→ «Продолжить». Экран уже открыт на вопросе «Вы находитесь в месте «Десять Городов». Что
делает ваш герой?» — сразу пиши реплику.

**Сколько стоит:** один ход ≈ 8 копеек (рассказчик `deepseek-v4.1-flash` + разборщик
команд). Бюджет профиля: 197,54 ₽ всего, израсходовано 97,54 ₽, **остаток 100,00 ₽** —
примерно 1200 ходов. Стенд сам не тратит: только на отправленную реплику и на подготовку
книги.

## 4. Что заведомо не работает или работает не так

- **Публичного входа нет.** Снаружи адрес не отвечает — сделано намеренно. Всё только через
  SSH-туннель на `127.0.0.1:19215`.
- **Подготовка книги моделью сегодня не запускалась** («Подготовить приключение» на экране
  «Новое приключение», «Подготовить игровой мир»). Это платные вызовы: ключ RouterAI
  настроен, но живая связь в этой сборке не проверялась — в `/api/health`
  `"connection_verified": false`, последний успешный платный вызов 06.11 в 13:57 UTC.
- **Живой ответ Мастера на настоящей модели в этой проверке не снимался** (платный вызов).
  Проверены экран игры, лист героя, вопрос Мастера и кнопки; сам ответ рассказчика — нет.
- **Модули из книг нарезаны автоматически** — «инструкции требуют проверки»; спойлерные
  тексты открываются только через «Подготовка Мастера».
- **Мусор от проверок в списках:** 31 черновик (много «Новая хроника», часть со статусом
  «Подготовка требует внимания») и 9 кампаний («Р239 Проверка», «Тест Р248», «Мира Р248»…).
  Это артефакты прогонов, не твои истории; открывать их не нужно.
- **Кнопка «Восстановить»** на экране игры неактивна, пока в кампании нет контрольной точки.
  «Сохранить контрольную точку» работает.
- **Первый экран кампании открывается 2,6–5,6 с** (замер по журналу действий) — не зависание.
- **Отказ вместо догадки — норма.** «Уклоняюсь»/«Прячусь» вне боя отвечают `No active Nat20
  combat`; «изучаю» там, где нечего изучать, отвечает «здесь нечего изучать». Это гейты,
  а не сбои. Укрытие механического бонуса не даёт — разметки укрытий в сцене нет.
- **Память кампании не бесконечна:** долгая сессия держится на памяти хоста, а не на всей
  переписке.

## 5. Если сломалось — что прислать

Одним сообщением:

1. **Скриншот экрана целиком**, не обрезанный.
2. **Текст ошибки дословно** — из плашки и, если видно, из консоли браузера
   (F12 → Console, красные строки).
3. **Время** (часы:минуты) и **номер шага** этой инструкции.
4. **Что делал последним** (кнопка / файл / реплика).
5. **Журнал** — одна команда, пароли и ключи она не печатает:

```bash
python3 ~/.hermes/scripts/solo_actions.py --errors
```

Показывает события за 30 минут: адрес, код ответа, миллисекунды, ошибки JS.
Шире окно — `-m 180` (минуты); весь хвост — `--tail 200`; машинный вывод — `--json`.
Сырой журнал: `runtime/web-local/actions.jsonl`.

Без `commit` из шага 1 поломку невозможно датировать — он в отчёте обязателен.
