# r150 — Сценарий из книги: локации, NPC и проверки с цитатой страницы

## ЦЕЛЬ

После импорта книги (r148) из неё должен получаться **модуль со сценой**: хотя бы одна
локация, хотя бы один NPC и хотя бы одна проверка со Сл, каждая — с цитатой и номером
страницы. Модуль обязан появиться в `GET /api/adventure/library/{bundle}/modules` и быть
`ready`.

## ЧТО ПРОВЕРЕНО ПРОРАБОМ (факты, не догадки)

Живой прогон на `127.0.0.1:19215`, файл `runtime/books/Hoard of the Dragon Queen RUS.pdf`
(8,9 МБ, 107 стр., текст читается: 501 244 символа, 76% кириллицы):

- импорт: `complete`, 107 страниц, 315 кандидатов (`chapter` 109, `instruction` 202,
  `table` 4), материалов 107 — все `kind='page'`;
- модулей: **0**. Нарезку делает только `AdventureLibrary.split_collection()` вручную.
- Готовые детекторы (`solo/adventure_worker.py:candidate_kind`) видят главы, таблицы,
  раздатки по заголовкам — это и есть бесплатный структурный сигнал.
- Пайплайн подготовки уже умеет: `PreparedWorldValidator.compile` принимает мир с
  локациями/NPC/проверками и **карантинит выдуманное** (сущность без цитаты в тексте
  страницы отбрасывается с `key='invented'`, `ready=False`).

## ЧТО СДЕЛАТЬ

1. **Сначала детерминированно, модель — только на неоднозначное.** Заголовки
   («Эпизод N», «Глава», «Локация», «NPC», «Проверка … Сл N») искать по тексту и
   типографике. То, что нашлось без модели, — не тратить на модель.
2. Модель звать **только** на страницы, где структура не нашлась, и требовать ответ
   строго в схеме `AdventureDefinition`/`world` с полями `document` (sha256), `page`,
   `quote`. Ответ без цитаты, которой нет в тексте страницы, — отбрасывать.
3. Нарезку модуля (`split_collection`, `confirm=True`) делать по найденным границам глав;
   если границ нет — один модуль на 1..N с честным `unsupported`.
4. **Бюджет денег.** Не больше одного модельного прохода на книгу в 107 страниц и потолок
   в задаче: остановиться, если суммарно ушло больше 5 ₽. Остаток лимита профиля до
   запуска и после — в отчёт (леджер `runtime/web-local/cloud-usage.sqlite3`).
5. Тест: `tests/test_module_scene_from_book.py` — на страницах-фикстуре из настоящего
   текста (не выдуманных) модуль получается `ready`, у каждой сущности есть `page` и
   `quote`, выдуманный NPC отброшен.
