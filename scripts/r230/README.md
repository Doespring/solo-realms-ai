# r230 — чем мерили

Файлы сняты с рабочего прогона без правок: так их запускали.

| Файл | Что |
|---|---|
| `cdp.py` | минимальный CDP-драйвер (свой Chromium, свои таймауты: экран игры держит главный поток дольше 5 с) |
| `measure.js` | сам замер одного экрана: кегли, зоны, зазоры, перелив, контраст, поле ввода vs `visualViewport`, плотность ленты, кубик |
| `r230_after.py` | обход 19 экранов × ширина × тема по HTTP-порту приложения, JSON + скриншоты |
| `measure_live.py` | то же для живой сборки без открытия кампании (экраны, которым кампания не нужна) |

Внутри — абсолютные пути рабочего каталога задачи (`/home/hermes/.hermes/kanban/workspaces/t_749e419f`).
Чтобы повторить: поднять приложение на своём порту (`--data-dir` — копия профиля), поправить
`PORT` (в `measure_live.py` — переменная окружения `SOLO_PORT`) и `APP` (куда класть PNG), затем

    python3 r230_after.py --phase after --themes obsidian,parchment --widths 375,390 --shots

Скрипты требуют `websockets` (системный python3 Hermes умеет); приложение — свой `.venv`.
