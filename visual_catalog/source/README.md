# Solo Realms AI — Asset Catalog (Obsidian Chronicle)

Версия: 2026-10-14. Каталог **источников**, а не скачанных изображений. Содержит проверенные страницы и подборки-кандидаты; бинарные ассеты не включены. Не означает, что все пакеты уже интегрированы, и не является автоматическим разрешением на скачивание или изменение игры.

## Выбранное направление
- Вся оболочка: пергамент, традиционный книжный стиль, сохранять доступность текста.
- Иконки: минималистичные обсидиановые тёмные силуэты, единые размеры, SVG.
- Боевые карты: механический слой координат, высот и тумана войны отдельно от декоративных ассетов.

## Значение полей
- `verification=verified`: была найдена карточка первоисточника, прямо указывающая лицензию. **Не** проверены лицензии внутри ещё не скачанных архивов.
- `verification=collection`: страница-подборка. Каждый элемент требует самостоятельной проверки; лицензия НЕ переносится со страницы подборки.
- `policy=core`: приоритетные для загрузки после согласования; `optional`: запасные; `reference`: изучить, скорее исключить по стилю; `research`: каталог для дальнейшего поиска; `excluded`: не включать в коммерческий комплект без дополнительного разрешения.
- `asset_downloaded=0`, `imported=0` в базе: ни один пакет не был скачан/интегрирован этим исследованием.

## Дальнейшие шаги (НЕ запущены)
1. После утверждения списка скачать `core` из официальных источников. Не обходить защиту сайтов и не брать подозрительные зеркала.
2. Для каждого архива проверить лицензию, сохранить оригинальное название, URL, автора, SHA256, лицензии и атрибуцию.
3. Развернуть файлы в отдельный raw-asset каталог вне пользовательских кампаний; не добавлять весь объём сразу в сборку EXE.
4. Нормализовать SVG/PNG, thumbnails и ассетные ключи. Настроить общие темы интерфейса и связанные карты ассетов.
5. Не включать материалы с NC или неясной лицензией в коммерческий дистрибутив.

## Чего нельзя делать
Не считать картинку боевой геометрией. Не смешивать pixel и hand-painted наборы без визуальной совместимости. Не дублировать 6000+ Dungeon Crawl tiles, если скачан Full ZIP. Не публиковать пакет Game-icons без авторов/атрибуций. Не публиковать шрифтовые файлы через чат.
