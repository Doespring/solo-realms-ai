## Браузерный блокер: измерено, а не предположено

Минимальный пример (без полного набора):

```
node -e chromium.launch({channel:'msedge',headless:true})
-> ERR:browserType.launch: spawn EPERM
```

Прямой запуск Edge стартует, но падает на `FATAL:mojo\public\cpp\platform` — среда
запрещает межпроцессный канал. Установка Playwright этого не изменит, поэтому 23 теста
помечены `BLOCKED BY ENVIRONMENT` и **не считаются пройденными**.

## Скрытый дефект под браузерным шумом

Два PDF-теста падали не из-за браузера. Цепочка установлена по шагам: `encounters == {}`
устарело → 503 на `/command-turn` → это `CloudUnavailable` → текст «Провайдер отклонил
параметры модели (HTTP 400)» → 400 вернул синтетический мок → мок не узнал пакет
`['atmosphere','confirmed','memory','npc','observation','packet_version','place']`.

Причина: маршрутизация мока опознавала рассказчика только по ключам конфликта, а пакет
строится вокруг сцены. `fallback()` — готовый корректный обработчик — был недостижим.

## Раунд 5: замечания критика закрыты

Критик подтвердил браузерный блокер и проверил правку мока, но нашёл важное:
**правка не была закреплена ни одним тестом**. Он откатил кортеж к старому виду, и
`test_desktop_pdf_smoke.py` всё равно дал `5 passed` — потому что реплика «Осматриваюсь»
несёт `description_sources`/`outcomes`, которые старый кортеж принимал. Регрессия могла
вернуться незамеченной.

Исправлено оба замечания:

1. **Условие сужено.** Было «любой из семи ключей», стало:
   `outcomes` | `player_words` | `description_sources` | (`place` и любой из `npc`/`atmosphere`/`observation`).
   Одинокий `{'place':'Перекрёсток'}` больше не миновает 400.

2. **Правка закреплена тестом** `tests/test_pdf_smoke_narrator_route.py` (5 passed):
   подаёт в **настоящий транспорт** мока пакет без `outcomes`/`player_words`/
   `description_sources` (только сцена) и ждёт 200; и наоборот — мусор и одиночный
   `place` ждут 400.

**Проверка мутацией.** Откатил кортеж к старому виду → новые тесты дали `2 failed, 3 passed`.
Восстановил → `11 passed` (вместе с двумя PDF-тестами). То есть тест действительно ловит
регрессию, а не сторожит сам себя.
