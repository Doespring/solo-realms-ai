# Оболочка Solo Realms AI 2.0

Литературная сцена — основной экран. Справа раскрывающиеся карточки героя, участников и кампании. Режим чтения убирает карточки. Основной ввод остаётся тем же свободным текстом и обращается к прежнему игровому циклу.

Три темы используют единые цвета --bg, --surface, --surface2, --text, --muted, --line, --gold, --input, --accent. Общие компоненты: .metric, .disclosure, .list-card, .settings-card, .form-grid, .button-row. Новые игровые панели должны использовать эти токены, текстовые ошибки и доступные подписи. CSS workspace.css расширяет существующий style.css без отдельной библиотеки и внешних ресурсов.

Масштаб интерфейса 90–125%, размер прозы 16–23 px, режим чтения и раскрытие карточек сохраняются в локальных предпочтениях браузера. Анимации учитывают prefers-reduced-motion. Адаптация проверена при 1366×768 и 480×800; это тесты размеров браузера, а не native DPI-проверка Windows.

Библиотека профилей отделена от текущих настроек кампании. Редактирование/удаление библиотечного профиля не меняет кампанию. Применение к кампании сохраняет её прежние настройки в master_versions. История библиотечных изменений хранится в profile_versions. Импорт добавляет профиль в библиотеку. Экспорт включает настройки и пользовательские инструкции, без API-ключей.

Литературные настройки входят в системный контекст Narrator; они управляют подачей. Инициативность, атмосферная суровость и предпочтение сражений не изменяют программную вероятность событий, сложность или броски. Механические настройки появятся через Ruleset Engine. Переключение внешних моделей и бюджетов выполняется в отдельном разделе API.

Подготовка desktop: web/ не зависит от браузерных расширений, внешних CDN или сборщика. Данные и HTTP backend остаются локальными. Масштаб, адаптивная ширина, доступная клавиатура и закрываемые dialog пригодны для WebView2. Реальная оболочка, адрес пользовательского каталога, корректное завершение сервера и EXE проверяются отдельно на этапе 8; их наличие здесь не имитируется.
