# Prototype GM — local source readiness

18 октября 2026. Используются существующие Interpreter, Narrator, Game,
Memory Context Builder, Preparation и Python/Nat20 backend. Нового движка,
хранилища памяти или провайдерного транспорта нет.

## Подключение

`solo.game.register_prototype_gm_api(app, store, game, *, preparation=None)`
подключён интегратором. Дополнительные маршруты:

- `POST /api/prototype/gm/prepared/{draft_id}/launch` — подтверждённый подготовленный
  мир, точная revision, валидируемый build и явно заданные encounters;
- `GET /api/prototype/gm/context/{campaign}?query=...` — текущий контекст мастера.

Обычный ввод идёт через существующий `/api/campaigns/{id}/command-turn`.
Interpreter получает текущий лист, публичную сцену, scoped memory, GameSnapshot
и объявленные возможности backend. Разговор/осмотр выбирает presentation;
механическое действие становится строго типизированным GameCommand. Числа,
допустимость и результат определяет backend. Narrator получает подтверждённые
результаты; его текст проходит существующую проверку канона перед показом.

Уточнения хранятся в существующем Store и переживают перезапуск. Новое отдельное
действие заменяет прежний вопрос, отказ не блокирует следующий ход. Для поиска
разрешён один дополнительный раунд до трёх catalogue ID, без полного каталога.
Подготовка использует существующий world resolver; неполный/неподдержанный источник
даёт конкретный отказ, а не подставную сцену. Нужен структурированный источник
либо явно подтверждённая sandbox-сцена. Обработка всей механики произвольного PDF
не заявляется. Механические encounters передаются явно; враги не выдумываются.

## Исправление диалога по подготовленному источнику

Обнаружено: private knowledge NPC сохранялось правильно, но техническое
`npc_state goals=[]` попадало первым в допустимые реплики fallback. Кроме того,
единая авторская запись содержала описание NPC перед ответом о мосте.

В `prototype_gm.dialogue_memories` отбираются только фактические записи знаний
из уже проверенного по ACL NPC-контекста. Из копии текста убираются явные метки
авторской разметки, исходные предложения ранжируются по словам вопроса.
Это выбор дословных источников, не семантический поиск и не свободный пересказ.
Не запрашиваются дополнительные приватные данные. ID/provenance/source_ref
сохраняются. Сам источник и память не переписываются.

Фразы технических переходов состояния и неподтверждённые заявления не становятся
знаниями. Если пригодного знания нет, fallback отвечает «Не знаю». Проверка канона
остаётся прежней. Произнесённая реплика записывается только как statement;
проза не меняет факты, Hero или Nat20 runtime.

```powershell
.venv/Scripts/python.exe -B -m pytest -q -p no:cacheprovider tests/test_prototype_integration.py::test_prepared_source_rogue_social_memory_through_registered_api tests/test_prototype_gm.py --basetemp "$env:TEMP/solo-prototype-2-tests"
```

**6 passed**. Неизменённый положительный API-тест загружает размеченный world.txt
через Preparation, создаёт Rogue/halfling и получает знание о мосте в разговоре.
Дополнительно проверены две темы, запрет технической реплики, отсутствие знаний,
две разные сцены/класса, сохранность механики при разговоре, уточнение/новое
действие, отказ/следующее действие, wizard Magic Missile, scoped memory и replay
после перезапуска. HTTP CloudLLM заменён MockTransport; те же пакет/verify работают
для offline mock. Предупреждения только прежние Starlette/lark deprecation.

Полный gate, EXE, живые или платные вызовы здесь не запускались. Настройки/размеры
облачного контекста и границы точности приведены в reports/PLAYABLE_AI_READINESS.md.

инцидента не затронуты.

## Заморозка после узких регрессий

Исправлена совместимость offline mock: зарегистрированный perception понимает
«следы»/«внимательность», короткий ответ продолжает вопрос после перезапуска,
новый самостоятельный ход заменяет прежний. Неизвестная фраза запрашивает
уточнение; явно необъявленная способность честно отклоняется.

Социальный журнал намеренно повышает version на один. Проверены неизменность
Hero/Nat20/economy/facts и повтор без второго события. Старый сценарий фонаря
проходит дальнейший бой, награду, сохранение и restore с текущими версиями.
SECRET_CANARY по-прежнему отсутствует в обоих пакетах.

Финальный узкий прогон: 28 + 5 = **33 passed**, включая настоящий старый Dash
browser-тест (не skip), подготовленный Rogue/halfling и две темы диалога.
Полный прогон/EXE/платные вызовы не запускались. Исходники заморожены для сборки;
собственных активных тестов/серверов нет. Очистка стенда согласуется с интегратором.
