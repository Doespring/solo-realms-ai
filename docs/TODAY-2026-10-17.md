## Что ещё не интегрировано

- Основной `command-turn` вызывает `CommandEngine` прежней механики Solo. Он не выбирает `Nat20GameEngine` для Nat20-кампании.
- Экран не проходит полный путь UI → мастер → Nat20 → память → UI.
- Существующие Solo-кампании не мигрируются; Nat20 работает только для явно созданной Nat20-кампании.
- Поддержан узкий сценарий: человек-воин 1-го уровня и ограниченный гоблин со скимитаром. Полные классы, заклинания, развитие, Foundry activities и тайминг Foundry не перенесены.
- Replay обеспечивает корректность, но стоит отдельного процесса и полного воспроизведения до 256 команд; производительность долгой кампании не оценена.

## Следующая контрольная точка

Для явно созданной Nat20-кампании один экранный ход должен пройти через Interpreter → `Nat20GameEngine` → Solo journal/memory → Narrator → экран. После атаки процесс закрывается, новый процесс восстанавливает тот же бой и продолжает без повторного броска. Обычная Solo-кампания продолжает использовать прежний backend.
