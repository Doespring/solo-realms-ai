# Этап3 — пакет опций конструктора

18 октября 2026. **READY / source freeze с измеренным ограничением первого запуска**. Только `solo/prototype_ui.py` и согласованный с Memory участок `solo/nat20_prototype.py`; новых HTTP API, UI-пагинации, правил/DTO, сборок или живых AI-вызовов нет.

## Изменения

Раньше семь категорий опций получались через11 страниц: каждая повторно проверяла release и строила полную категорию, затем отрезала страницу. Теперь внутренний Python helper `catalog_batch(categories)` проверяет прежний release один раз и использует **ту же** общую проекцию entries для выбранных категорий. Публичный catalog сохраняет фильтр, пагинацию, порядок, DTO, known_issue и execution_status; вычисления attack_profile всех монстров не запускаются.

`creation_options` кеширует только статичные schema/defaults/choices и возвращает их отдельную копию. Каталог проходит release-проверку **каждый вызов**, поэтому старый result-LRU больше не скрывает изменение содержимого. Каждый выбранный JSON читается один раз; неизменяемые варианты билдера, ограничения и доступность каталога сохранены. Проверки pin/bundled_release, `content_verification_cache.py` и `nat20_content.py` не менялись.

## Проверки и границы

Три актуальных уникальных contract-кейса зелёные. Первый узкий прогон: **2 passed +1 failed, 2,68 с**. Ошибка была в тестовом ожидании: Comprehend Languages уже имел статус native_candidate до изменения, а тест ошибочно ожидал unsupported. Тест теперь выбирает существующий unsupported из сохранённого baseline (Alarm); повторён **только этот кейс:1 passed,1,45 с**. Исходный красный XML сохранён; результаты не называются одним clean suite.

Проверены точное равенство полного ответа baseline, один release/одно чтение выбранного JSON, отсутствие вычисления всех monster attack profiles, защита от изменения возвращённых static/schema данных, прежние пагинация/query/known issues. На маленьком синтетическом каталоге: исходник проверен, изменение без смены pin отказано, после явного нового pin показано новое имя — cached static не скрывает изменение. Тесты не меняли реальный каталог.

Memory передал ownership только batch-helper/shared entry projection. Этот freeze **заменяет прежний SHA nat20_prototype.py** из `reports/stage3-content-cache/freeze.json`; остальные cache-файлы остаются dependency с прежними SHA (указаны в новом freeze). Его22 теста и engine14 не повторялись. Routing/native runtime/Stage1/cloud и `.1–.5` не менялись. Полных наборов/EXE/ZIP нет; Solarimus AI обновляет root.
