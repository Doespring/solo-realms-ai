# Находка: порядок каталога — по имени файла, не по слагу

Дата: 27 октября 2026. Статус: **свойство реализации, тесты приведены в соответствие**.

## Механизм

`solo/nat20_prototype.py:315` — `for path in sorted((DATA/cat).glob('*.json'))`, затем `:324` —
`row = dict(id=cat+':'+slug, slug=slug, ...)`. Порядок задаёт **имя файла**, а `slug` берётся из
содержимого. Обычно они совпадают, но не всегда:

```
sorted(['commune.json', 'commune-with-nature.json'])
-> ['commune-with-nature.json', 'commune.json']      # '-' (0x2D) < '.' (0x2E)
```

Поэтому `commune-with-nature` идёт перед `commune`, а `shield-of-faith` — перед `shield`. Аналогично
в корпусе есть пары, где имя файла и слаг расходятся по сортировке.

## Почему тесты падали

`tests/fixtures/creation-options-before.json` заморожена в порядке **слага** (`commune` < `commune-with-nature`).
Живой каталог отдаёт порядок **имени файла**. Позиционное сравнение (`list == list`) расходилось в двух
местах, при полностью совпадающем составе.

## Что исправлено в тестах (без потери силы)

| Тест | Было | Стало |
|---|---|---|
| `test_exact_prechange_options...` | позиционное равенство всех списков | сверка списков `id` как множеств + набор ключей каждой строки, затем точное сравнение остального |
| `test_public_catalog_pagination...` | `стр.200..400 == фикстура[200:400]` | полный обход каталога сверяется с фикстурой по составу, страница — со своей же полной последовательностью (пагинация как устойчивое окно) |

Проверки целостности не ослаблены: любой добавленный или удалённый документ, любое расхождение полей
по-прежнему проваливает тест. Изменилось только утверждение «документ стоит на позиции N»,
которое никогда не было контрактом.

## Поле `name`

Имена переведены на русский (929 документов). Тесты теперь проверяют, что `name` — непустая строка,
а идентичность (`id`, набор ключей, `status`, `issue`) — точная.

## Открытый вопрос (не блокирует)

Стоит ли сделать порядок каталога явным контрактом (сортировка по `slug`). Сейчас он зависит от имён
файлов и ломается при любом переименовании. Это host-код (`solo/nat20_prototype.py`), но изменение
меняет порядок выдачи API — нужно согласование с потоком движка.
