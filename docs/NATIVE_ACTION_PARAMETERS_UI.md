## Что доступно в прежней панели

Дополнительные параметры свёрнуты и зависят от операции и реального `action_schema` сервера:

| Операция | Необязательный выбор |
| --- | --- |
| Предмет | `charges_to_spend`: сколько зарядов потратить |
| Способность | `pool_points`: сколько очков запаса потратить |
| Атака / рывок / отход | `use_bonus_action`: обычное либо бонусное действие |
| Атака | `two_handed`: хват одной/двумя руками |
| Толчок | `shove_push`: сбить с ног / оттолкнуть |
| Подготовка / реакция | `reaction_trigger` из enum схемы, выбранное подготовленное заклинание и ячейка |
| Заклинание / предмет / способность | `direction` X/Y, исключённые цели области |
| Заклинание | `as_ritual`: явный выбор, допустимость определяет Native |

Границы чисел взяты из схемы, а не из самостоятельных формул или предполагаемого запаса. Пустое значение **не отправляется**; явные `false`, допустимый `0`, координата `0` и явно очищенный список исключений отличаются от отсутствующего поля. Движок окончательно проверяет расход, свойства оружия, цели, дальность и допустимость. Ресурсные поля не обязательны.

У перемещения больше нет незаметного назначения `(0,0)`: обе координаты пусты до выбора игрока. Неполная пара координат просит заполнить вторую или очистить обе. Пустой `target_ids` не добавляется автоматически. Общий dispatch/retry остаётся прежним; версия захватывается вместе с показанной формой, чтобы устаревшая форма не подставляла новую версию к старым параметрам. Локальный отказ одного действия не отключает класс.

## Проверка: 1 passed, 50.90 с

`tests/test_native_parameters_ui.py` + `.cjs`: новый изолированный профиль, `SOLO_TEST=1` до app import, настоящий HTTP API и pinned Native, MockLLM, Edge **1280×800**, внешние соединения заблокированы. Реальных AI-вызовов **0**, JavaScript ошибок **0**, memory.audit чистый.

Три реальных применения через существующую панель и прежний GameCommand:

1. **Wizard 5 / Wand of Magic Missiles:** игрок выбрал **2 заряда**. Сервер выполнил действие, тест оборвал только доставку успешного ответа. Повтор отправил идентичные параметры, версию и request_id. Итоговый native counter потратил **2**, а не 4 заряда; ввод сохранился.
2. **Burning Hands:** выбраны цель, первая ячейка, направление **[1,0]**, `as_ritual:false`. Настоящий Native принял параметры; число ячеек первого уровня стало **3**. Число эффектов и урон клиент не вычислял.
3. **Paladin 2 / Lay on Hands:** выбраны существующие способность, healing activity и герой; **3** очка запаса переданы как `pool_points`. Настоящий native counter `feature_use:lay-on-hands` подтвердил расход **3**.

Отдельно внутри того же браузерного smoke явно использован **dispatch spy**, без игры, для проверки сериализации отсутствующих значений, bool false, slot 0, направления с нулевой координатой, enum реакции, pool min=1 и отсутствия автоматического перемещения/пустого target_ids. Один **явный HTTP 409 fixture** проверил прежнюю ветку version conflict: обновление/управление сохранились. Реальное выполнение реакций, толчка и всех вариантов оружия этим прогоном не сертифицировано.

Первый промежуточный прогон нашёл недостающий доступный label у новых select; добавлен `aria-label`. Второй остановился на ожидании helper: spy получает `parameters`, а реальный HTTP использует существующий `action`; исправлен только тест. Последний полный узкий прогон прошёл. Другие owner/PDF/gate проверки не повторялись.
