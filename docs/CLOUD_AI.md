# Cloud AI Adapter

Рабочий стек сохранён: FastAPI, SQLite, свободный текстовый интерфейс. Active provider — solo/cloud.py: CloudLLM. Старый локальный адаптер сохранён в reports/cloud2/history/kobold_llm_pass17.py только для исследования прошлых результатов.

Интерфейс совместимого провайдера: HTTPS Base URL, Bearer authentication, GET /models при поддержке, POST /chat/completions. В запросе две роли system/user; локальных ChatML-префиксов нет. Список моделей не закреплён. Кандидаты найдены в публичном каталоге RouterAI, но не выбраны и не объявлены победителями.

Настройки сохраняются в data/cloud-profiles.json, ключи — отдельно в data/cloud-secrets/<UUID>.dpapi. Windows CryptProtectData/UnprotectData защищают ключ контекстом текущего пользователя. Нет plaintext fallback. Frontend передаёт новый ключ только одноразовым локальным PUT; backend возвращает лишь key_present. Валидационные ошибки не возвращают input. Экспорт кампании/профиля Мастера не содержит ключ. Ключ следует вводить самому пользователю; в чат его присылать не нужно.

При запуске нет inference warmup, запросов к локальному AI или тестовой прозы вместо недоступной модели. Без ключа, выбранной модели и явного enabled облачный запрос не отправляется. Локальные история, настройки, сохранения и программные операции остаются доступны.

Модель Interpreter выбирается отдельно от Narrator. Для Interpreter используются штатный контракт Interpretation и локальная валидация Plan. json_schema/json_object отправляются только согласно указанной совместимости; без поддержки strict outputs остаётся локальная валидация. Валидный JSON не доказывает понимание намерения. Narrator по умолчанию получает свободную прозу без JSON-обёртки; его текст не меняет Game State и не превращается в память-факт. Reasoning delta не показывается, текстовые think-блоки фильтруются.

Поток разобран как SSE data-события, [DONE] обязателен; usage может прийти отдельным финальным событием. Отмена закрывает HTTP-поток и освобождает lock. Это не гарантия того, что провайдер прекратил вычисление или списание. Нет автоматических платных повторов. Ошибки сети, таймаута, HTTP, потока и контракта учитываются отдельно. Ошибка Narrator не повторяет уже подтверждённые броски и события.

Затраты хранятся в data/cloud-usage.sqlite3, отдельно от игрового отката: paid запрос не становится бесплатным при undo. Для вызова сохраняются кампания, request/turn, сессия, провайдер, модель, назначение, timestamps, token usage/reasoning, TTFT, полное время, retry link, статус, цена и источник цены. Тексты/ключи в ledger не записываются.

Перед запросом резервируется консервативная сумма по UTF-8 byte estimate и максимальному выходу. Это оценка, не настоящий tokenizer. Неизвестные тарифы блокируют вызов. Учитываются лимиты запроса, сессии и дня (по умолчанию UTC+4 / Самара). Нулевая квота блокирует ненулевую оценку. Near-limit warning — 80%. Подтверждение превышения действует 10 минут, привязано к профилю/URL/валюте/сессии/кампании/ходу/полному body и используется один раз. Оно не запускает запрос автоматически.

usage токены имеют приоритет. usage.cost используется как provider-reported только если валюта известна и совпадает. Иначе стоимость рассчитывается по реальным usage токенам, либо сохраняется предварительный резерв как оценка. Валюты не смешиваются. Предварительный бюджет не может гарантировать внешнее списание при неверных тарифах, изменившихся ценах/маршрутизации или неизвестных правилах провайдера. После фактического ответа расходы могут превысить предварительную оценку; следующие вызовы будут ограничены.

Стандартные temperature/top_p/seed/schema передаются только при заявленной поддержке; stream_options.include_usage — отдельное подтверждаемое свойство профиля. Неподдерживаемые model-specific knobs не отправляются автоматически. Модели и параметры можно сменить между запросами без перезапуска.

Источники: [RouterAI quickstart](https://routerai.ru/docs/guides/overview/quickstart), [параметры](https://routerai.ru/docs/guides/overview/parameters), [endpoint capabilities / единицы тарифов](https://routerai.ru/docs/guides/overview/provider-selection), [Windows DPAPI](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata). Публичный каталог и проверенные IDs — reports/cloud2/stage1/routerai-public-catalog.json. Для текстовых цен RouterAI подтверждены RUB/token; UI переводит их в цену за миллион. Не распространяйте такую конвертацию на другие единицы или неизвестного провайдера.

Проверено через явный httpx.MockTransport и HTTP/SSE TestClient; реальной оплаченной генерации не было. Качество русского, actual TTFT/throughput и цены реального подключения ещё не проверены. В production mock fallback отсутствует.
