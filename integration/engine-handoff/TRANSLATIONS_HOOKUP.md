# Подключение переводов к мастеру персонажа

Справка к `DELIVERY.md` (14.152-14.175). Как получить русские названия вместо английских.

## Главное: в движке уже есть 1704 названия

`vendor/nat20/packages/dnd5e-engine/src/dnd5e_engine/labels.py` — таблицы русских названий с
пометкой об источнике (PHB 2024 RU и номера страниц для `LABELS`):

| Таблица | Записей | Что покрывает |
|---|---|---|
| `RULES_ENTITIES` | 996 | заклинания, черты, классы, подклассы, виды, предыстории |
| `ITEM_LABELS` | 546 | все предметы корпуса |
| `LABELS` + `PAGES` | 72 | термины правил, с номерами страниц |
| `GAME_TERMS` | 42 | навыки и игровые термины |
| `FAILURE_REASONS` | 33 | причины отказа действия |
| `CONDITIONS` | 15 | состояния |

## Рекомендуемое решение — вызов движка, а не свой словарь

```python
from dnd5e_engine.labels import label

name = label(slug)          # по СЛАГУ, не по английскому имени
```

Проверено исполнением — одна функция `label()` покрывает все категории:

```
spell       fireball    -> 'Огненный шар'
class       fighter     -> 'Воин'
species     human       -> 'Человек'
background  soldier     -> 'Солдат'
feature     second-wind -> 'Второе дыхание'
item        longsword   -> 'Длинный меч'
condition   blinded     -> 'Ослеплённый'
```

**Важно: сигнатура `label(term: str, *, fallback: str | None = None) -> str`.** Неизвестный термин
возвращается как есть (или `fallback`) — движок не выдумывает переводов.

**Ключ — СЛАГ.** `label()` НЕ чувствителен к регистру: `label('Augury')` и `label('augury')` дают
одинаковое `'Предзнаменование'` (проверено исполнением). Но английское имя с пробелом (`'Acid Arrow'`)
в таблицах не найдено — там ключи-слаги с дефисами. Поэтому подставлять надо `slug`, а не `name`.

## Где сейчас английский

`solo/nat20_wizard.py:157` — единственная точка формирования подписи:

```python
def _entry(slug, name, *, disabled_reason=None, detail=None):
    return {"id": slug, "name": name, "disabled_reason": disabled_reason, "detail": detail}
```

Вызывается в **семи** местах:

| Строка | Что |
|---|---|
| `:219` | виды |
| `:251` | подклассы |
| `:275` | классы |
| `:316` | подклассы (варианты) — легко пропустить |
| `:337` | предыстории |
| `:569` | пулы черт и навыков (`_pool_name`) — легко пропустить |
| `:694` | заклинания |

Все семь передают английское имя: `str(spell.name)`, `str(doc.name)`, `row["name"]`.

## Минимальная правка

```python
from dnd5e_engine.labels import label as _label

def _entry(slug, name, *, disabled_reason=None, detail=None):
    return {
        "id": slug,
        "name": _label(slug, fallback=name),
        "disabled_reason": disabled_reason,
        "detail": detail,
    }
```

Правка НЕ требует менять ни один из семи вызовов: `slug` уже передаётся первым аргументом во всех.
`fallback=name` сохраняет английское имя для слагов, которых нет в движке.

## Резервный вариант: файлы из этой поставки

Если приложение не может импортировать `dnd5e_engine.labels` (изоляция, другая версия движка),
используйте `ru_core.json` (369) и `ru_items.json` (546). Оба **приведены к формулировкам движка**
(14.173-14.174), коллизий 0, поэтому переключение между источниками не меняет подписи.

```json
{"spell:acid-arrow": {"category": "spells", "name": "Acid Arrow", "name_ru": "Кислотная стрела"}}
```

Ключ — `<префикс>:<slug>`. Префиксы: `spell`, `classes`, `species`, `backgrounds`.

## Одной правки `_entry` НЕДОСТАТОЧНО

Проверено критиком и чтением кода. Правка `_entry` переводит заклинания, классы, подклассы, виды и
предыстории. Остальное идёт другими путями.

**(1) Черты на листе персонажа — мимо `_entry`.**

*Ниже — цитата исходника с номерами строк, а НЕ исполняемый код: префиксы `:929` и т. п. — это номера строк файла.*

```python
:929  def _feature_name(loader, slug):
:931      return str(doc.name) if doc is not None else str(slug)   # АНГЛИЙСКОЕ
:958  {"id": slug, "name": _feature_name(loader, slug)}   # features
:962  {"id": slug, "name": _feature_name(loader, slug)}   # feats
```

Нужна отдельная правка `:931`: `_label(slug, fallback=str(doc.name))`.

**(2) Навыки: переведены 4 из 18.**

Два разных факта, которые легко спутать:

- `SKILL_DISPLAY_NAMES` (`dnd5e_engine/rules/skills.py:84-103`) содержит **английские** значения для всех 18
  навыков — проверено: 16 из 18 равны слагу с заменой `_` на пробел и заглавными (`animal_handling` ->
  `Animal Handling`). То есть этот словарь НЕ переводит ничего.
- Отдельно `label()` переводит **4 из 18** (`acrobatics`, `athletics`, `perception`, `stealth`) — проверено
  запуском.

Поэтому ниже: `_pool_name:486-489` берёт `SKILL_DISPLAY_NAMES` и возвращает английское имя (не «как есть»
в смысле слага — а именно английскую подпись); после правки через `label()` переводятся 4 из 18.

```
acrobatics -> Акробатика        athletics  -> Атлетика
perception -> Внимательность    stealth    -> Скрытность

arcana -> 'arcana'              insight -> 'insight'
persuasion -> 'persuasion'      animal_handling -> 'animal_handling'
... (14 из 18 возвращаются как есть)
```

**(3) Мастерство оружия: 1 из 8.**

```
topple 'topple'   vex 'vex'   sap 'sap'   nick 'nick'
push 'push'       graze 'graze'   cleave 'cleave'
slow -> 'Замедление'   (единственное переведённое)
```

**Итог по объёму для интегратора:** ДВЕ обязательные правки. `_entry` (главное) и `_feature_name:931`.
Третье — словари навыков и мастерства в движке — только если интегратор решит их переводить; без этого
игра работает, но 14 навыков из 18 и 7 видов мастерства останутся английскими.
