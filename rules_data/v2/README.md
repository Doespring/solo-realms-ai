# Hybrid Rules Data v2.1

PHB 2024, глава 1: 41 пункт оглавления, 131 запись в пяти пакетах, **377/377 целевых проверок пройдены**. Исходные 11 межкнижных образцов и определения v1 сохранены. Полная конвертация трёх книг не завершена.

[Карта покрытия](coverage/phb-01.json) связывает подразделы, SHA источника, PDF/печатные страницы, классификацию, зависимости, типизированные факты, обработчик, поведенческую проверку и готовность. Извлечение главы завершено; автоматизация всей главы — нет. Имена угроз, чувств, состояний и других ссылочных правил не заменяются выдуманными определениями глоссария.

`routing.schema.json` принимает прежний формат 2.0.0 и новый 2.1.0. В 2.1.0 обязательны revision, dependencies, behavior_tests и readiness; математические факты имеют дополнительные ограничения типов. `coverage.schema.json` проверяет карту. Текст главы кешируется один раз в `evidence/phb-008-033.txt`; источник сверён по SHA, таблицы и неоднозначные места — также визуально. Человеческая проверка источников ожидается.

Классифицируется конкретная ветвь: deterministic выполняется при подтверждённых входах; adjudicated оставляет смысловой выбор Мастеру; hybrid разделяет смысловую и формальную стадии. Готовность хранится отдельно. Отсутствующий обработчик не превращает формальную механику в нарративное правило.

[Адаптер](PRODUCTION.md) связывает только три прежних определения преимущества/помехи и шесть проверенных определений главы с существующими проверками характеристики, навыка и спасброском. По умолчанию и после перезапуска активации нет. Бой, нокаутирование, Wish и неподдержанные эффекты этим адаптером не исполняются.

Локальный математический модуль дополнен точным рациональным округлением, к100, процентной проверкой и заменой одной кости. Он не получает полномочий на ресурс, случайность или канон. Для переброса нужны доверенный RNG, разрешение эффекта и расход ресурса; последний ещё не подключён.

AI возвращает только предложение. Engine-команды требуют подтверждения, проверяют редакцию, зависимости, версии, ACL и идемпотентность; результат и канон фиксирует существующая транзакция. Художественное описание отделено. PDF/AI-текст не исполняется и не выбирает Python-обработчик.

Целевой запуск: `.venv/Scripts/python.exe -X utf8 -B -m rules_data.testing.run_targeted --chapter-one`.
[Машинный отчёт](reports/phb-01/summary.json), [JUnit](reports/phb-01/targeted.junit.xml), [журнал](reports/phb-01/targeted.log). В карте проверки отказа/предложения отличаются от проверки формального поведения: они не сертифицируют смысл решений AI или заблокированные эффекты.

История: `reports/executability/` — 87 проверок, `reports/production/` — прежние 136. Текущий запуск включает эти 136 и целевые проверки нового пакета. Дальше: явные зависимости и следующие главы PHB, затем полный DMG 2024, затем MM 2025 в семействе dnd2024. Пользовательские базы, UI и синхронизированные источники не менялись; платных API и EXE нет.
