# Solo Realms AI

Настольная D&D 2024 для одного игрока: книгу приключений загружаем в PDF, правила
считает движок, а Мастера играет модель. Проект — прототип: полный цикл «книга →
модуль → герой → сцена → ход → карта» проходит, но не все правила книги считаются.

## Как устроено

Две части, и это главное правило проекта:

- **Nat20** — единственный калькулятор D&D 2024 (ХП, инициатива, атаки, спасброски,
  ресурсы, эффекты). Живёт в `vendor/nat20`, версия закреплена пинами.
- **Solo** (`solo/`, `web/`) — мир, состояние, транзакции, память, права доступа,
  учёт расходов на модель и весь веб-интерфейс. Своих правил не выдумывает: если
  движок чего-то не умеет, хост это честно показывает, а не подменяет расчётом
  «на глаз».

Второго движка и тихого отката на старые правила быть не должно.

## Что работает сейчас

- **Правила книги героя (PHB 2024): 332 записи.** Считаются — **174** (161 проверено
  прогоном по подмножеству движка, 7 ядром, 6 адаптером). **76** отданы Мастеру:
  там, где решение за человеком, движок отдаёт модели факты и подсказку, а не
  выдумывает числа. **82** упираются в возможности движка — под них нужны патчи
  вендора, они перечислены в отчётах.
- **Подклассы: 36** — по три на каждый из 12 классов, **183 умения**. Данные
  выписаны из книги с номерами страниц; свободный набор SRD даёт только по одному
  подклассу на класс.
- **Разбор PDF**: текст постранично, геометрия страницы, границы глав по
  колонтитулам, материалы (карты, раздатки, иллюстрации) по геометрии и подписям.
  Проверено на четырёх книгах: Hoard of the Dragon Queen (107 страниц, 8 модулей),
  The Rise of Tiamat (99, 12), The Wild Beyond the Witchlight (256, 10),
  Icewind Dale: Rime of the Frostmaiden (323 страницы, 143 МБ, 8 модулей, 44 карты).
- **Игра**: кампания из модуля, лист героя, ход, бой, карта и раздатки, журнал.

## Модели

Роли разведены, у каждой свой тариф:

- `interpreter` — разбор реплики игрока;
- `narrator` — проза Мастера;
- `pdf_analyst` — разметка сцен по книге;
- `vision` — изображения (карты, раздатки): отдельная роль, потому что не каждая
  модель принимает картинки.

Настройка — в профиле приложения (`runtime/web-local/cloud-profiles.json`), ключи
лежат в `cloud-secrets` и в git не попадают.

## Запуск

**Linux (сервер, стенд владельца).** Служба `solo-app` под systemd (user-юнит,
`Restart=always`), порт `127.0.0.1:19215`, лаунчер
`~/.hermes/scripts/serve_solo.py`. Проверка: `curl -s localhost:19215/api/health` —
в ответе `commit` и `build`, их сверять с `git log -1`.

**Windows.** `Web.cmd` запускает веб-версию в отдельном профиле
`runtime/web-local` (в git не входит):

```powershell
$env:SOLO_DATA_DIR=Join-Path (Get-Location) 'runtime/web-local'
.venv/Scripts/python.exe -X utf8 -B scripts/start_cloud.py --data-dir "$env:SOLO_DATA_DIR" --port 19215 --open
```

`Desktop.cmd` — отдельный desktop-режим, `Prototype-Offline.cmd` — офлайн без
обращений к модели.

## Тесты

338 файлов проверок. Гоняются из корня, на отдельном профиле данных:

```bash
SOLO_TEST=1 .venv/bin/python -m pytest tests/test_<тема>.py -q
```

Живую базу владельца (`runtime/web-local`) тестами не трогать: они работают на
копии профиля.

## Структура

- `solo/` — сервер приложения, правила хоста, PDF-разбор, API, память, деньги.
- `web/` — интерфейс (экраны подготовки, игры, раздаток).
- `vendor/nat20/` — закреплённый движок правил. Правки только через `PATCHES.json`
  и проверку пинов, иначе загрузчик откажется стартовать.
- `rules_data/v2/chapters/` — правила книги с состоянием готовности по каждой
  записи; `integration/nat20/phb-2024/` — данные подклассов из книги.
- `tests/`, `scripts/`, `tools/`, `packaging/` — проверки и инструменты.
- `docs/` — ТЗ и заметки; `reports/` — итоги задач и аудиты.
- `runtime/` — данные, книги, кэш, ключи. **В git не попадает.**

## Ветки и архив

- `main` — снимок текущего рабочего дерева (обновляется автоматически).
- `work/nat20-engine` — работа по движку правил.
- `feature/*` — ветки задач приложения.

Приватный архив: `github.com/Doespring/solo-realms-ai` (виден только владельцу).

## Лицензии и источники

- Правила и данные SRD — по лицензии CC-BY-4.0.
- Данные из купленной книги (PHB 2024, приключения) переносятся с маркером
  источника: лицензия `user_private`, происхождение `phb-2024-ru`, номер страницы.
  PDF-книги и эти данные **в git не кладутся** (`runtime/books`,
  `integration/nat20/phb-2024/`). Разделить источники можно одной выборкой по
  маркеру.

## Что честно не работает

- **82 правила** ждут правок движка: умения, чей эффект он не умеет считать.
- Книги-сканы без текстового слоя не разбираются: нужен OCR, его в проекте нет.
- Живая проза Мастера на платном ключе пока не проверена — прогоны шли на
  офлайн-заглушке.
- Финальная приёмка пути в браузере (книга → игра) не завершена.
