SOLO REALMS AI 2.1.4-preview.10-mock — Windows x64 — MOCK AI

Preview10: «Рывок» работает текстом и кнопкой через Nat20. На следующем ходу бюджет восстанавливает движок. После загрузки показана текущая история; отменённые события находятся в отдельной свёрнутой ветке. Истинное уточнение «Осматриваю» → «следы» сохранено. Только воин, магия недоступна.

Эта сборка работает БЕЗ облачного AI и без платных запросов. Настоящая механика Nat20 0.7.0 исполняется локально. Ответы mock заранее ограничены; это не проверка качества облачного мастера.
Запустите SoloRealmsAI.exe. Мои приключения → Письмо у старого фонаря · воин → Начать испытание.
Реплики: «Поговорю с Ладой», «Осматриваю домик», «Осматриваю следы». После проверки войдите во двор кнопкой, подойдите и атакуйте. «Второе дыхание» используйте до атаки. Можно играть подтверждёнными кнопками. «Рывок» тратит действие; атаковать после него в тот же ход нельзя.
Справа откройте «Сохранения и восстановление» и сохранитесь посреди боя. Закройте приложение, запустите снова и продолжите кампанию. Подтверждённый бой восстанавливается через Nat20 replay.
Профиль по умолчанию: %LOCALAPPDATA%/SoloRealmsAI-Preview10-Mock. Рабочие кампании/API-профили автоматически не копируются.
Границы: обычный воин 1-го уровня, один гоблин, нет магии и Level Up. При 0 HP сценарий остановлен; загрузите сохранение. Полная процедура смерти не реализована, окончательная смерть не объявляется.
После победы выдаются одно письмо и одна XP-награда; затем доступен отдых. Повторная награда запрещена.
Требуются Windows 10 19041+/11, WebView2 и .NET. Отдельный Python не нужен. Не перемещайте EXE отдельно от _internal. Цифровой подписи нет. Установщик preview.6 — другая версия.

Ниже сохранена справка предыдущего релиза; она описывает обычный режим исходников, а не возможности этого mock preview.

Запуск: SoloRealmsAI.exe. Сохраняйте весь каталог рядом с EXE: _internal содержит встроенный Python/backend и интерфейс.
Obsidian Chronicle: 65 локальных ресурсов, шрифты, лицензии и миниатюры работают без интернета. Авторство — _internal/web/visual/ATTRIBUTION.md; исходный каталог — _internal/visual_catalog/source/.
Начните с «Нового приключения»: загрузите материалы и/или опишите историю. После подготовки выберите создание героя текстом или пошаговый конструктор. AI предлагает мир; программа проверяет источники и механические данные. Для проверенной версии Hoard доступен пролог перед Гринестом (осмотр, герой, сохранение); городское столкновение ещё закрыто. Неподтверждённые зависимости текущей сцены блокируют её, дальнейшие главы остаются в карантине. Исходники и черновик сохраняются. Полная автоматическая подготовка произвольной книги пока не подтверждена.
Выбор на карте или в инвентаре сообщает контекст. Действуйте репликой в чате.
Установщик — SoloRealmsAI-Setup-2.1.4-preview.6.exe.
Python вручную не нужен. Требуются Windows 10 19041+/11, .NET и WebView2 Evergreen Runtime.
Данные — %LOCALAPPDATA%\SoloRealmsAI, отдельно от установленной программы.
Удаление программы сохраняет профиль и резервные копии.
В изолированном QA-профиле проведены реальные API-проверки в общем разрешённом лимите; тестовые расходы не дают разрешения на автоматические запросы из обычной игры. Настройте свой HTTPS-провайдер и лимиты в разделе «Нейросети и API»; автоматически провайдер/модель не выбираются.
Правила D&D покрыты частично. Известные пределы: полный SRD, заклинания/магические вещи/классовое развитие/бесконечная песочница/автономная NPC-симуляция не реализованы.
Смертельный механический исход без заранее объявленного риска сохраняется, а необратимый переход останавливается; окончательное домашнее правило не придумано.
Реальный EXE и установщик проверены на текущем Windows с WebView2; чистая Windows VM без Python ещё не проверена. Издательская цифровая подпись отсутствует.
Подробности и источники — _internal/assets/DESKTOP.md, RULESETS.md, COMBAT.md, MAPS.md, INVENTORY.md, WORLD.md и SRD_ATTRIBUTION.md.
Обновление — повторная установка нового выпуска после закрытия игры; автообновления не включены.
Схема сохранений 12. Старый EXE 2.0 не открывает новую схему; для возврата используйте исходную резервную копию, не новую базу.

Adventure Intelligence: локальная библиотека больших PDF/ZIP/карт, закрытая подготовка Мастера и проверяемые сценарные инструкции. Извлечение книги не означает её готовность. Пользовательские книги и сохранения не входят в установщик.
RouterAI: новый выключенный профиль Qwen/DeepSeek/Venice/Gemini, ручной выбор рассказчика, отдельные бюджеты. Gemini работает только с выбранным извлечённым текстом; vision/OCR не реализованы. Thinking OFF требует реальной проверки поддержки.

Создание героя: проверенный ограниченный каталог первого уровня — воин, плут, волшебник, жрец; редакции 2014 и 2024 разделены. Полный Character Creator, Level Up и применение всей магии не завершены. Обычный интерфейс не позволяет произвольно менять механические характеристики.
Известные P0: реальные рассказчики могут добавлять неподтверждённые факты или ошибаться в языке; полноценная подготовка книги ещё не прошла приёмку. Сборка предназначена для проверки нового процесса и не объявлена финальным релизом.

API & GM Hotfix: ключ DPAPI общий для четырёх ролей. «Включить облачный AI» требует явного разового лимита; при отсутствии маршрутов/тарифов предлагает выбрать их до подтверждения. Включение не вызывает модель. Общий лимит не сбрасывается автоматически по дате или после перезапуска.
Локальная база правил хранится отдельно в профиле. Пользовательские PHB/DMG не распространяются в сборке. DMG неполный: доступны только реально предоставленные страницы; GM-фрагменты не отправляются без проверки. Проверенное правило можно спросить у Мастера вне роли, с указанием источника и страницы. Текст книги сам по себе не реализует новую механику.
При вопросе о причине события NPC без подтверждённых сведений получает программный ответ «Не знаю» без генерации. Это ограниченная защита; произвольная художественная проза модели всё ещё может ошибаться.
