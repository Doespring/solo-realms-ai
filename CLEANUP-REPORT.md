# Очистка проекта — preview.6

Удалено около **11,3 ГиБ**: прежние Windows-сборки и архивы, старые отчёты и спецификации, промежуточная сборка, тестовые профили, резервные копии, игровые кампании, сохранения, черновики и импортированные приключения. Очищены и `data` проекта, и `%LOCALAPPDATA%/SoloRealmsAI`. Исходные PDF и ZIP пользователя в «Загрузках» не удалялись.

Оставлены текущие исходники, действующие регрессионные тесты, документация, лицензии, каталог визуальных ресурсов, интерфейсные ассеты, зависимости разработки и Windows-сборка **2.1.4-preview.6**. Удалена только проверка шаблона больше не используемого локального KoboldCpp; полезные проверки бюджетов и интерпретации перенесены в автономные тестовые fixtures.

Игровые базы заново созданы пустыми: **0 кампаний, 0 черновиков, 0 комплектов приключений**. SQLite integrity — `ok`, ошибок foreign keys нет. Защищённые ключи, API-профили и история расходов сохранены локально без изменений. В архив они не входят. Справочник правил сохранён локально отдельно от кампаний.

Проверки: текущие **563 теста**, чистый старт интерфейса с пустым профилем и без вызовов моделей. Исполняемый код приложения не менялся; сохранены рабочие portable EXE и установщик preview.6. Их прежние проверки Windows не выдаются за новый прогон этой очистки. Платных запросов не выполнялось.

Архив `SoloRealmsAI-clean-2.1.4-preview.6.zip` содержит исходники, тесты, рабочий каталог `dist/SoloRealmsAI`, текущий установщик и инструмент сборки Inno Setup. Исключены `.git`, непереносимая `.venv`, пользовательские базы, ключи, библиотеки PDF, кэши и дублирующие ZIP сборок. Встроенная стандартная библиотека Python сохранена как необходимая часть EXE. `.git` и рабочая `.venv` оставлены только на исходном компьютере. Файлы архивируются с контрольными суммами, ZIP проверяется полностью.

Запуск после распаковки: `SoloRealmsAI/Desktop.cmd`. Для новой кампании потребуется заново импортировать свой PDF или ввести описание. Ограничения пролога preview.6 описаны в `FIRST-PLAYABLE-PREVIEW6.md`.

Машинные результаты: `reports/cleanup/deleted.json`, `empty-profiles.json`, `fresh-start.json`, `pytest.log`. Внешний файл `.manifest.json` рядом с ZIP содержит размер и SHA-256 архива; внутри — `ARCHIVE-MANIFEST.json` с хешами каждого файла.
