# Solo Realms AI — сайт

Играбельная веб-версия: вход → создание героя → игра в браузере.
Механику считает движок `dnd5e_engine` (Nat20), мастер пишет прозу по правилам —
внешняя LLM не нужна, ключи не нужны, интернет не нужен.

## Запуск

Из корня проекта:

```bash
.venv/bin/python site/app.py
```

Дальше открыть <http://127.0.0.1:19216> → «завести аккаунт» → создать героя →
«Играть».

Порт и база задаются переменными окружения:

```bash
SOLO_SITE_PORT=8080 SOLO_SITE_DB=/tmp/site.db .venv/bin/python site/app.py
```

В режиме отладки (перезапуск на правку кода) исключайте каталог базы, иначе
каждый ход игрока пишет в `site.db-wal` и сервер перезапускается на ровном месте:

```bash
.venv/bin/python -m uvicorn app:app --app-dir site --reload \
  --reload-exclude "data/*" --reload-include "*.py"
```

С наружного адреса (если надо показать не только себе):

```bash
SOLO_SITE_HOST=0.0.0.0 SOLO_SITE_PORT=8080 .venv/bin/python site/app.py
```

## Что внутри

| файл | что делает |
|---|---|
| `site/app.py` | маршруты FastAPI, сессии на cookie, пароли PBKDF2 |
| `site/store.py` | SQLite без ORM: аккаунты, сессии, герои, приключения, лента |
| `site/heroes.py` | справочники вида/класса/предысторий, лист героя через движок |
| `site/narrator.py` | мастер без LLM: ключевые слова → проверка + Сл, текст сцены |
| `site/views.py` | весь HTML строками, без шаблонизатора |
| `site/static/site.css` | тёмная тема, адаптив 375 / 1440 |

Зависимости — только то, что уже стоит в `.venv` проекта: `fastapi`, `uvicorn`,
`python-multipart` (для форм), `dnd5e_engine`. Ни `jinja2`, ни `itsdangerous`, ни ORM.

## Правила

- Числа (хиты, класс брони, бонус мастерства, навыки, спасброски, исход проверки)
  берутся из движка. Сайт их не считает — только показывает.
- Характеристики: 27 очков, значение 8–15; проверяется на сервере, не только в JS.
- Пароль: PBKDF2-SHA256, 210 000 итераций, соль на пользователя.
- Сессия: случайный токен в `HttpOnly` cookie, `SameSite=Lax`, 30 дней.
- База: `site/data/site.db` (WAL). Удалить файл — начать с нуля.

## Тесты

```bash
.venv/bin/python -m pytest tests/test_site.py -q
```

14 тестов: очки характеристик, лист через движок, распознавание проверок,
полный путь игрока через HTTP (регистрация → герой → приключение → ход).
